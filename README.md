# Link Hunter Market

Маркетплейс для обмена и продажи групп Telegram и WhatsApp с системой модерации, авторизацией, корзиной и оплатой.

## Технологический стек
- Фронтенд: Next.js 15, React, TypeScript, Tailwind CSS, ShadCN UI
- Бэкенд: Next.js API Routes, tRPC
- База данных: PostgreSQL (Prisma ORM)
- Авторизация: NextAuth.js
- Оплата: Stripe (или ЮKassa)

## Основные функции
- Список групп Telegram/WhatsApp с фильтрами
- Система обмена группами через модерацию
- Система продажи групп и оплаты
- Личный кабинет пользователя
- Админ-панель для модерации

## Начало работы
```bash
npm install
npm run dev
```
